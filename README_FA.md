# City Sofal – Reflection Retoucher (Web)

نسخه وب عمومی ابزار روتوش انعکاس محصولات سیتی سفال؛ آماده انتشار در GitHub و استقرار روی Render.

## وضعیت معماری
- Frontend: HTML/CSS/JavaScript (قلم‌مو روی Canvas)
- Backend: FastAPI
- Image processing: OpenCV + NumPy
- Deployment: Render Free
- خروجی: PNG با ابعاد اصلی، WebP بهینه‌شده، یا ZIP شامل هر دو
- ذخیره‌سازی: بدون ذخیره دائمی فایل‌ها
- دسترسی: عمومی، بدون حساب کاربری

## امکانات
- آپلود JPG / PNG / WebP
- قلم قرمز برای انتخاب انعکاس ناخواسته
- قلم آبی برای محافظت از بخش‌های مهم و براق
- پاک‌کن و پاک کردن کامل ماسک‌ها
- محافظت خودکار محافظه‌کارانه از پیکسل‌های بسیار روشن و کم‌اشباع
- پردازش موضعی با OpenCV (Telea یا Navier-Stokes)
- اسلایدر مقایسه قبل و بعد
- خروجی PNG اصلی، WebP مناسب وب، یا هر دو در ZIP
- محدودیت حجم، ابعاد و تعداد پردازش برای کنترل مصرف منابع
- مسیر health check برای Render و UptimeRobot

## استقرار در GitHub و Render
1. این پروژه را در یک مخزن GitHub آپلود کنید.
2. در Render گزینه **New + → Blueprint** را انتخاب کنید.
3. مخزن GitHub را متصل کنید و Blueprint را از روی `render.yaml` بسازید.
4. سرویس `city-sofal-reflection-retoucher` را انتخاب و Deploy کنید.
5. بعد از Deploy، آدرس `https://YOUR-SERVICE.onrender.com/healthz` باید JSON با وضعیت `ok` نشان دهد.

روش جایگزین: در Render یک **Web Service** جدید بسازید، مخزن را متصل کنید، Runtime را Python، Build Command را `pip install -r requirements.txt` و Start Command را `uvicorn app.main:app --host 0.0.0.0 --port $PORT` قرار دهید.

## UptimeRobot
پس از انتشار، یک HTTP(s) monitor با URL زیر بسازید:
`https://YOUR-SERVICE.onrender.com/healthz`

فاصله بررسی ۵ دقیقه را انتخاب کنید. توجه: استفاده از UptimeRobot برای جلوگیری از خواب سرویس Free تضمین‌شده یا مورد تأیید Render نیست و ممکن است با شرایط یا سیاست‌های پلتفرم تغییر کند. مصرف 750 ساعت رایگان ماهانه نیز باید کنترل شود؛ یک سرویس 24/7 حدود 720 ساعت در ماه مصرف می‌کند.

## محدودیت Hybrid در نسخه Free
در این نسخه، موتور ترکیبی به‌صورت دو مرحله‌ای آماده شده است: OpenCV مسیر پایه و fallback است؛ LaMa یک موتور AI اختیاری و قابل فعال‌سازی است. LaMa در فایل `requirements-ai.txt` تعریف شده و با متغیر `ENABLE_LAMA=true` فعال می‌شود. بااین‌حال اجرای مدل LaMa روی Render Free با 512MB RAM قابل اتکا نیست و ممکن است باعث OOM و توقف سرویس شود؛ بنابراین در `render.yaml` عمداً غیرفعال است. برای فعال‌کردن AI واقعی، از سیستم محلی دارای RAM کافی یا سرور/سرویس پردازش تصویر مناسب استفاده کنید. اگر LaMa نصب یا بارگذاری نشود، برنامه خودکار به OpenCV برمی‌گردد.

## امنیت و استفاده عمومی
- سرویس عمومی است و ورود/رمز عبور ندارد.
- محدودیت پیش‌فرض: 8 پردازش برای هر IP در هر ساعت (محدودکننده حافظه‌ای و قابل ریست با restart).
- محدودیت آپلود: 10MB و 16MP.
- فایل‌ها در دیسک یا دیتابیس ذخیره نمی‌شوند.
- برای استفاده عمومی گسترده، rate limit حافظه‌ای کافی نیست؛ باید reverse proxy / Redis، CAPTCHA، صف پردازش و سیاست سوءاستفاده اضافه شود.
- این نسخه برای بتای کم‌ترافیک طراحی شده، نه سرویس تجاری پرترافیک.

## نکته کیفیت
Inpainting همیشه بخشی از سطح را حدس می‌زند. برای حفظ دقیق لعاب، فقط انعکاس ناخواسته را با قلم قرمز انتخاب کنید و هایلایت‌های طبیعی را با قلم آبی محافظت کنید. محافظت خودکار فقط پیکسل‌های بسیار روشن و کم‌اشباع را نگه می‌دارد و تشخیص کامل انعکاس انسان از بازتاب لعاب نیست.

## اجرای محلی
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
سپس `http://127.0.0.1:8000` را باز کنید.
